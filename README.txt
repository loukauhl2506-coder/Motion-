IMPORTANT
To install as a proper iPhone home-screen web app, it must be served from an HTTPS website. Opening index.html directly from Files will not enable PWA installation/offline service-worker features.

EASY FREE HOSTING OPTION (GitHub Pages)
1. On a computer, sign in to GitHub and create a new public repository named motion-training.
2. Upload all four files from this folder to the repository root (not the ZIP itself).
3. In the repository, open Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
5. Wait for GitHub Pages to publish. Open the published https://…github.io/motion-training/ URL in Safari on your iPhone.
6. Tap Share → Add to Home Screen. If shown, enable Open as Web App, then tap Add.

DATA & PRIVACY
Workout logs, checkmarks, measurements and notes are stored in the browser's localStorage on your device. Export a backup from History regularly. Clearing Safari website data can remove the records. Export/import backups when changing devices. The app does not send training data to a server.

VIDEO LINKS
Each exercise's Watch demo link opens a YouTube search for that exercise plus a proper-form tutorial. It does not embed or endorse a particular video. The Form guide link opens the ACE Fitness exercise library.

HEALTH NOTE
This plan is general fitness guidance. With previous ACL reconstruction and recurring knee stiffness/swelling, use pain-free ranges and seek a physiotherapist's assessment if symptoms recur. Do not train through swelling or instability.
